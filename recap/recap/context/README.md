# Lesson material

Drop lesson or reference material here (`.pdf`, `.txt`, `.md`). The server loads it at startup
(or upload more from the Notes page). It is used to:

- boost speech-recognition accuracy for subject terms,
- predict how Alex means to finish a sentence when he stalls,
- show a short definition under the captions when he uses a key term,
- ground the live AI notes.

`Oculomotor_nerve_palsy_infographic.md` is the text of the Group 5 A&P infographic, used for the
demo (`python client/simulator.py --lesson`). Remove it for a different class.
